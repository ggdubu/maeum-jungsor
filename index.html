상대방 기록

사람마다 대화와 관찰 내용을 따로 저장해요. 이름 대신 별칭을 사용해도 됩니다.

기록은 현재 사용 중인 브라우저의 로컬 저장공간에 보관됩니다. 브라우저 데이터 삭제·기기 변경 전에 백업하세요. OCR 실행 시 라이브러리와 언어 데이터는 인터넷에서 내려받지만, 선택한 이미지를 OCR 서비스 서버로 업로드하지 않고 브라우저에서 처리합니다.

대화 분석

보내지 않을 편지

상대에게 실제로 보내지 않을 말을 마음껏 적어보세요. 저장하거나, 기록된 상대의 특성을 참고해 가상 답장을 받아볼 수 있어요.

가상 답장은 실제 상대의 생각이 아니라, 저장된 특성과 입력한 맥락을 바탕으로 만든 연습용 시뮬레이션입니다.
